webpify demo uploads

Each section shows the files the page received from its file input, as its own upload code would see them. With webpify enabled for this site, images in sections 1–3 and 5 arrive as .webp and videos in section 6 as .mp4. Section 4 only accepts JPEG and PNG, so webpify leaves it alone.

1. Plain input

<input type="file" accept="image/*" multiple> with an addEventListener("change") handler.

2. React 18 onChange

A React component that keeps the picked files in state.

3. Inside a shadow root

A web component whose file input lives in an open shadow root.

4. JPEG/PNG only

accept="image/jpeg,image/png". A WebP would be rejected here, so the original files should arrive.

5. Dropzone.js

Dropzone 5 on a <form class="dropzone">. Clicking goes through a hidden file input that Dropzone adds to <body>; dragging files onto the area goes through a drop event. Uploading is switched off, the list shows what Dropzone queued.

6. Video

<input type="file" accept="video/*" multiple>. With webpify on, videos arrive as H.264 .mp4 files, at most 1080p and 30 fps. A video that already is a compact MP4 arrives unchanged, and so does one this browser can't read (an iPhone HEVC video in Firefox, for example); the notice says why.
