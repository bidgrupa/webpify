SOURCE CODE AND BUILD

The uploaded source archive is the repository at this version's tag. The extension's JavaScript, HTML and CSS are not minified or generated: every file in the package is copied as-is from extension/, except
- manifest.json, trimmed to Firefox's keys by scripts/package.mjs
- pkg/webpify_bg.wasm and pkg/webpify.js, the image converter: Rust (src/) compiled to WebAssembly, with the JS bindings generated by wasm-bindgen.

To rebuild, on Ubuntu 24.04 x86_64 (the reference build environment):
1. sudo apt install build-essential curl zip
2. Install rustup: curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y && . "$HOME/.cargo/env"
3. cargo install wasm-bindgen-cli --version 0.2.129 --locked
4. From the source root: ./build.sh (rust-toolchain.toml installs Rust 1.93.1 and the wasm32 target)
5. node scripts/package.mjs firefox (Node 22 or later)
dist/firefox/ is then identical to the submitted package. README.md, "Building from source", has the details.

TESTING

No account is needed. webpify does nothing until it is turned on for a site:
1. Open https://bidgrupa.github.io/webpify/, a test page with several kinds of upload fields.
2. Click the webpify button (in the toolbar or the Extensions menu), turn on "Convert uploads on this site" and allow access when Firefox asks. Only that one site is requested.
3. In section 1, choose one or more JPEG or PNG photos. The page lists the files it received: .webp files of type image/webp, smaller than the originals. A notice at the bottom of the page shows the savings.
4. Section 4 only accepts JPEG and PNG, so webpify leaves those files unchanged on purpose.
